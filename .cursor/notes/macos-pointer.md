# Mac ポインタのサイズと色

**最終更新**: 2026-09-27

## 要点

- 初日の `./install.sh`（本物の HOME）で `macos/defaults.sh` が書き込む
- 値: サイズ 2、塗りつぶし赤寄りオレンジ、枠線白（2026-08-23 取得、09-27 再確認で同じ）
